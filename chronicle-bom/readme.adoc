== About

Imports are most effective when used for defining a "library" of related artifacts that are generally part of a multiproject build. It is fairly common for one project to use one or more artifacts from these libraries. However, it has sometimes been difficult to keep the versions in the project using the artifacts in synch with the versions distributed in the library. The pattern below illustrates how a "bill of materials" (BOM) can be created for use by other projects.

The root of the project is the BOM pom. It defines the versions of all the artifacts that will be created in the library. Other projects that wish to use the library should import this pom into the dependencyManagement section of their pom.

== Coordinated source builds

Normal consumers use the released dependency versions in this BOM.
`-Dbuild-all=true` activates `build-all-snapshots`, which selects the current
development snapshots for the coordinated source build. The existing TeamCity
Build All Branch job already supplies this flag.

The standalone `assertions-enabled` and `assertions-disabled` modules retain
release 1.0.0: Build All does not build those modules, so selecting their
unpublished snapshots would block dependency resolution before compilation.

Build and install the producer repositories before their consumers, using the
same branch where available. Keep Queue's main and test jars from the same build.
Snapshot names alone do not prove which source revision supplied an artifact;
record producer revisions and artifact hashes when qualifying a composition.

Update the snapshot properties when producer development versions advance.
`-Dbuild-all=false` leaves the release selection unchanged. An explicit Maven
property, such as `-Dchronicle.queue.version=...`, still takes precedence.

The imported-BOM controls exercise Maven's actual profile activation, Queue
main/test alignment and explicit property precedence. Run them with each JDK:

[source,shell]
----
python chronicle-bom/src/test/python/check_build_all.py --repository /path/to/isolated/maven-cache
----

On Windows, add `--maven C:/path/to/mvn.cmd` if Maven is not on `PATH`.
The check stages a unique local BOM coordinate and does not publish artifacts.
