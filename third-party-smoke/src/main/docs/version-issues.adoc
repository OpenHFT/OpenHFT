* *Netty 4.1.128.Final* :: 4.1 remains the Java 8-compatible line.

* *OpenTelemetry 1.56.0* :: Still supports Java 8; monitor release notes for any baseline change.

== Bytecode Level Exclusions

These dependencies stay excluded from `enforceBytecodeVersion`:

* *org.hsqldb:hsqldb 2.7.4* :: Compiled for Java 11 (classfile version 55).
The `jdk8` classifier provides Java 8 bytecode.
* *org.mongodb:bson-record-codec* :: Compiled for Java 17 (uses Java records).
Action: confirm whether this is still resolved transitively with the 4.11.5 driver set; exclude if unused.

== SLF4J Binding Profiles

To keep smoke-test builds clean, SLF4J bindings are validated one at a time via Maven profiles:

* `slf4j-simple` (active by default)
* `slf4j-nop`

`ClassLoadingSmokeTest` asserts that exactly one binding provider is present on the classpath.
