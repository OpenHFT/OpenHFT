== SLF4J Binding Conflicts

The test classpath intentionally includes multiple SLF4J implementations (pom.xml lines 220-227, 230-237):

* `slf4j-simple`
* `slf4j-nop`

This configuration triggers SLF4J warnings: "Multiple bindings were found on the class path"

*Decision*: Warnings are tolerated to validate all bindings load correctly without failures (see SMOKE-DEC-006 in decision-log.adoc).

*Future*: Consider separate test execution groups if warning noise becomes problematic for developers.
