== Scope
These requirements cover the third-party-smoke module, which validates that dependencies declared in `third-party-bom` remain usable on Java 8 (baseline) and Java 21 (current LTS).

== Functional Requirements

*SMOKE-TEST-001* Class loading coverage :: Every artefact in `third-party-bom` must have at least one class successfully loaded on Java 8 baseline. This requirement is satisfied by `ClassLoadingSmokeTest`, which dynamically generates coverage grouped by dependency category. Implementation: `ClassLoadingSmokeTest.classLoads()`.

*SMOKE-TEST-002* Behavioural coverage :: Critical dependency families must demonstrate minimal operational usage beyond class loading (no external services). Implementation: category-based smokes below.

*SMOKE-TEST-003* Observability and metrics :: Prometheus metrics registration and OpenTelemetry tracer initialisation must succeed. Implementation: `MinimalObservabilitySmokeTest.*`, `MetricsAndFfiSmokeTest.prometheus*`.

*SMOKE-TEST-004* Serialisation smoke :: JSON and YAML serialisation libraries must round-trip simple objects. Implementation: `MinimalSerializationSmokeTest.*`, `JettisonSmokeTest.jettisonJsonObjectRoundTrip()`.

*SMOKE-TEST-005* Networking smoke :: Web server frameworks (Undertow, Jetty, Netty, Grizzly, MINA) must initialise and bind to port `0` without external traffic. Implementation: `MinimalNetworkingSmokeTest.*`, `NioAndNetworkStacksSmokeTest.*`, `JettyWebSocketSmokeTest.*`, `OkHttpSmokeTest.okHttpCanCallMockWebServer()`.

*SMOKE-TEST-006* Logging smoke :: Log4j2, SLF4J bindings, and JUL bridge must create loggers and emit test messages. Implementation: `MinimalLoggingSmokeTest.*`, `LoggingExtendedSmokeTest.*`.

*SMOKE-TEST-007* Utilities and tooling :: Collections (Trove4j), compression (Snappy), code generation (JavaPoet), classpath scanning (ClassGraph), CLI/JSON/time/email utilities, and native access (JNA/JNR) must perform basic operations. Implementation: `MinimalUtilitiesSmokeTest.*`, `CliJsonHttpTimeEmailSmokeTest.*`, `CommonsLibrariesSmokeTest.*`, `ClassGraphSmokeTest.*`, `MetricsAndFfiSmokeTest.jnr*`, `JavaPoetSmokeTest.javapoetCanGenerateSimpleHelloWorldClass()`.

*SMOKE-TEST-008* Database smoke :: MongoDB connection string parsing and HSQLDB in-memory round-trip must succeed without external servers. Implementation: `MinimalDatabaseSmokeTest.*`, `DatabaseAndSchemaSmokeTest.hsqldbInMemoryRoundTrip()`.

*SMOKE-TEST-009* Build and packaging :: Git operations, Maven model parsing, ProGuard construction/parsing, FIX messages, and annotation presence must succeed. Implementation: `GitBuildAndAnnotationsSmokeTest.*`, `ProGuardParserSmokeTest.*`, `QuickFixSmokeTest.canBuildNewOrderSingleMessage()`, `AnnotationsAndGuavaTestlibSmokeTest.*`, `JavaxInjectSmokeTest.injectAnnotationsPresentAtRuntime()`.

*SMOKE-TEST-010* Test frameworks and mocking :: JUnit Jupiter, params, platform launcher, migration support, Vintage, Mockito, EasyMock, PowerMock presence, and JMH annotations/options must execute. Implementation: `Jupiter*`, `JUnit*`, `MockitoSmokeTest.*`, `EasyMockSmokeTest.*`, `PowerMockPresenceSmokeTest.*`, `JmhSmokeTest.*`, `LoggingExtendedSmokeTest.junit*` where applicable.

== Non-Functional Requirements

=== Operational Requirements

*SMOKE-NF-O-001* Bytecode enforcement :: Maven enforcer must reject dependencies with bytecode > Java 8 (classfile version 52.0), with documented exclusions only. Current exclusions: `org.hsqldb:hsqldb` (Java 11 bytecode), `org.mongodb:bson-record-codec` (Java 17 bytecode). Implementation: `maven-enforcer-plugin` with `enforceBytecodeVersion` rule.

*SMOKE-NF-O-002* Multi-JDK validation :: Tests must pass on Java 8 (baseline) and Java 21 (current LTS). Contributors must verify smoke tests pass on both JDK versions before raising pull requests.

*SMOKE-NF-O-003* Documentation currency :: When tests or dependencies change, update documentation in `src/main/docs/` in the same commit to prevent drift. This includes updating requirement references, version notes, and decision logs.

=== Performance Requirements

*SMOKE-NF-P-001* Fast execution :: Smoke tests avoid network I/O and persistent side effects; target short wall clock time and deterministic results. Tests must not require external services, database connections, or network calls.

*SMOKE-NF-P-002* Parallel safety :: All tests must be thread-safe and support parallel execution. Maven Surefire may execute tests concurrently; tests must not share mutable state or have execution order dependencies.

=== Security Requirements

*SMOKE-NF-S-001* No credentials :: Tests must not require external services, credentials, or network access. All validation must be self-contained and executable in isolated CI environments without authentication or external dependencies.

== Toolchain Expectations
* Java 8 as baseline compiler and runtime target
* JUnit 5 (Jupiter) as primary test framework with JUnit 4 vintage engine for backwards compatibility
* Maven Surefire for test execution
* `enforceBytecodeVersion` with `extra-enforcer-rules` for bytecode validation
* Checkstyle (sun_checks.xml) and SpotBugs for code quality
