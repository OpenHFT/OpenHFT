== Scope

These requirements cover the third-party-smoke module, which validates that dependencies declared in `third-party-bom` remain usable on Java 8 (baseline) and Java 21 (current LTS).

== Functional Requirements

*SMOKE-TEST-001* Class loading coverage :: Every artefact in `third-party-bom` must have at least one class successfully loaded on Java 8 baseline.
This requirement is satisfied by `ClassLoadingSmokeTest`, which dynamically generates 85+ tests grouped by dependency category.
Implementation: `ClassLoadingSmokeTest.classLoads()`.

*SMOKE-TEST-002* Minimal usage coverage :: Critical dependencies (observability, serialisation, networking, logging) must demonstrate minimal operational usage beyond class loading.
This requirement ensures that basic runtime behaviour works correctly, not just classpath resolution.

*SMOKE-TEST-003* Observability smoke :: Prometheus metrics registration and OpenTelemetry tracer initialisation must succeed.
Implementation: `MinimalObservabilitySmokeTest.prometheusCountersCollect()`, `MinimalObservabilitySmokeTest.openTelemetryInitialises()`.

*SMOKE-TEST-004* Serialisation smoke :: JSON, YAML, XML serialisation libraries must round-trip simple objects.
Implementation: all tests in `MinimalSerializationSmokeTest` covering JSONAssert, SnakeYAML, XStream, Jackson jsonSchema, and Jettison.

*SMOKE-TEST-005* Networking smoke :: Web server frameworks (Undertow, Jetty, Netty, Grizzly) must initialise without starting actual listeners.
Implementation: all tests in `MinimalNetworkingSmokeTest` validating framework construction and configuration.

*SMOKE-TEST-006* Logging smoke :: Log4j2 and SLF4J must create loggers and emit test messages.
Implementation: `MinimalLoggingSmokeTest.log4j2Usage()`, `MinimalLoggingSmokeTest.slf4jUsage()`.

*SMOKE-TEST-007* Utilities smoke :: Collections (Trove4j), compression (Snappy), code generation (JavaPoet), native access (JNA/JNR) must perform basic operations.
Implementation: all tests in `MinimalUtilitiesSmokeTest` covering utilities, collections, compression, and native libraries.

*SMOKE-TEST-008* Database smoke :: MongoDB connection string parsing and HSQLDB driver loading must succeed without actual database connections.
Implementation: `MinimalDatabaseSmokeTest.mongoConnectionStringParses()`, HSQLDB driver loading in `ClassLoadingSmokeTest.assertHsqldbDriver()`.

*SMOKE-TEST-009* Legacy JUnit4 :: Verify JUnit4 vintage engine supports legacy test cases to ensure backwards compatibility for projects migrating from JUnit 4 to JUnit 5. Implementation: `LegacyJUnit4SmokeTest.vintageEngineRuns()`.

== Non-Functional Requirements

=== Operational Requirements

*SMOKE-NF-O-001* Bytecode enforcement :: Maven enforcer must reject dependencies with bytecode > Java 8 (classfile version 52.0), with documented exclusions only.
Current exclusions: `org.hsqldb:hsqldb` (Java 11 bytecode), `org.mongodb:bson-record-codec` (Java 17 bytecode).
Implementation: `maven-enforcer-plugin` with `enforceBytecodeVersion` rule in pom.xml lines 546-578.

*SMOKE-NF-O-002* Multi-JDK validation :: Tests must pass on Java 8 (baseline) and Java 21 (current LTS).
Contributors must verify smoke tests pass on both JDK versions before raising pull requests.

*SMOKE-NF-O-003* Documentation currency :: When tests or dependencies change, update documentation in `src/main/docs/` in the same commit to prevent drift.
This includes updating requirement references, version notes, and decision logs.

=== Performance Requirements

*SMOKE-NF-P-001* Fast execution :: Smoke tests avoid network I/O and persistent side effects; target < 30 seconds total execution.
Tests must not require external services, database connections, or network calls.
Current execution time: approximately 2.5 seconds total (class loading ~1.3s, minimal usage ~1.2s).

*SMOKE-NF-P-002* Parallel safety :: All tests must be thread-safe and support parallel execution.
Maven Surefire may execute tests concurrently; tests must not share mutable state or have execution order dependencies.

=== Security Requirements

*SMOKE-NF-S-001* No credentials :: Tests must not require external services, credentials, or network access.
All validation must be self-contained and executable in isolated CI environments without authentication or external dependencies.

== Toolchain Expectations

* Java 8 as baseline compiler and runtime target
* JUnit 5 (Jupiter) as primary test framework with JUnit 4 vintage engine for backwards compatibility
* Maven Surefire for test execution
* `enforceBytecodeVersion` with `extra-enforcer-rules` for bytecode validation
* Checkstyle (sun_checks.xml) and SpotBugs for code quality
