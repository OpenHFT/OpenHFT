= Meaningful Message JSONL Schema
:toc:
:toclevels: 2

JSONL output is optional and is written only when `--jsonl <path>` (CLI) or the `jsonl` check property is set.
Each line is a standalone JSON object.

== Record Types

=== Run Record

Fields:

* `type`: `"run"`
* `schema_version`: integer schema version
* `tool`: tool name
* `dry_run`: boolean
* `verbose`: boolean
* `rank_resource`: classpath resource used for ranks
* `rank_out`: optional, path used when dry-run writes rank output

=== File Record

Fields:

* `type`: `"file"`
* `file`: normalised file path (relative to the run root when possible)
* `file_level_advice`: array of file-level advice blocks
* `line_level_advice`: array of line-level advice blocks
* `candidates`: verbose-only array of all candidates (present when `verbose` or `dry_run` is true)
* `legacy_suppressions`: verbose-only array of legacy RuleId codes that were suppressed

== Advice Block Shapes

File-level advice block:

* `advice_id`
* `rank`
* `title`
* `intent_intro`
* `intent_outro`
* `hint_a`
* `hint_b`
* `checklist`
* `anti_patterns`
* `line`: optional, line used for the file-level warning
* `items`: optional list (for example, overused words)
* `metrics`: optional object with file-level metrics

Line-level advice block:

* `advice_id`
* `rank`
* `title`
* `intent_intro`
* `intent_outro`
* `hint_a`
* `hint_b`
* `checklist`
* `anti_patterns`
* `occurrences`: array of occurrences

Occurrence fields:

* `line`
* `source`
* `message_literal`: optional
* `message_expr`: optional
* `snippet`: optional, trimmed single line

Candidate fields (verbose or dry-run):

* `line`
* `advice_id`
* `rule_id`
* `source`
* `message_literal`: optional
* `message_expr`: optional
* `metrics`: optional per-candidate metrics

Metrics fields may include:

* `word_count`, `meaningful_word_count`, `total_word_count`, `effective_meaningful_word_count`
* `placeholder_count`, `key_value_label_count`
* `min_word_count`, `max_word_count`, `min_meaningful_word_count`, `max_word_length`
* `comparison_operator`, `comparison_left_operand`, `comparison_right_operand`
* `string_search_method`, `string_search_target`, `string_search_arg`

== Schema Versioning

`schema_version` increases on breaking changes (renames, removals, or type changes).
Additive fields may be introduced without a version bump.

== Example

[source,json]
----
{"type":"run","schema_version":1,"tool":"MeaningfulMessage","dry_run":false,"verbose":false,"rank_resource":"net/openhft/quality/mm-advice-ranks.properties"}
{"type":"file","file":"quality/src/main/java/...","file_level_advice":[],"line_level_advice":[]}
----
